## [0.1.0] - 2026-08-17

### Added
- Initial release of unofficial Python client for Weathercloud.
- Reverse-engineered OpenAPI 3.0.3 specification (`docs/openapi.yaml`).
- Interactive Swagger UI and local CORS proxy support.
- Sensor reading, historical stats, and station metadata endpoints.
